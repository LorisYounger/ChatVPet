# ChatVPet

## 桌宠的生命只有两分钟，我要给她完整的一生

**ChatVPet**，即桌宠语言模型，是我们为《虚拟桌宠模拟器》开发的专属 AI。我们曾开放过一段时间的桌宠 AI 聊天测试，发现未经专门训练的 AI 表现很差，经常反应慢、乱说话。

除了训练模型，我们也在开发配套的聊天处理库和桌宠插件。目前已有知识库、聊天历史、日记和工具调用，用来给 AI 补充相关信息，并调用桌宠功能。后续打算将聊天和操作分开，加上说话时的表情，让桌宠做完事情后再告诉玩家结果。

## 模型与开发方向

新一版计划基于 **Qwen3.5-9B** 做 LoRA 微调。

受样本数量限制，目前只接受简体中文内容的提交，其他语言的支持留待后续。

聊天和操作分工如下：

- **ChatVPet** 负责说话和选择表情。平时聊天直接回答，需要查询信息或操作桌宠时，再交给 **ToolCallAI**。
- **Process** 负责查找相关知识和记忆，将玩家的话、桌宠的回答和可用工具一起交给 **ToolCallAI** 判断。
- 桌宠插件负责检查数量、预算和当前状态，并执行操作。完成后传回结果，再由 **ChatVPet** 告诉玩家。

**ToolCallAI** 指其他能力较强的模型，例如 DeepSeek 或 OpenAI 的模型。

比如，玩家问“够不够钱买”，就查询价格和余额；玩家让买才买，买到了再说买好了。重新生成回答时，也不能重复购买。后续还会加入查阅旧聊天、查看截图和选择动画的功能，具体计划见 [ChatVPetProcess](ChatVPetProcess.md)。

## 时间线

* 征集用户聊天数据：[ChatGPT for 创意工坊作者](https://steamcommunity.com/sharedfiles/filedetails/?id=3157090829)
* 训练初代模型：指令监督微调和从零开始训练都会尝试，比较效果。**目前在这一步。**
* 征集初代模型聊天数据：回答时询问用户是否符合预期，并混合 ChatGPT/ChatVPet 的回答让用户分辨。
* 训练二代模型：等待数据累计至 1 万条后，训练奖励模型。
