# ChatVPet

## 桌宠的生命只有两分钟，我要给她完整的一生

**ChatVPet**, 即桌宠语言模型, 给《虚拟桌宠模拟器》做的专属 AI. 我们曾经测试开放过一段时间的桌宠AI聊天，测试下来发现未进行训练的AI效果非常不好。存在大量反应慢，乱说话等问题。

除了训练模型, 我们也在做配套的聊天处理库和桌宠插件. 目前已经有知识库、聊天历史、日记和工具调用, 可以给 AI 补充相关信息, 也可以让它调用桌宠的功能. 后续打算把聊天和操作分开, 加上说话表情, 做完事情再回来告诉玩家结果.

## 模型与开发方向

新一版打算基于 **Qwen3.5-9B** 做 LoRA 微调,

由于样本数量原因,本项目暂不支持除了简体中文以外的提交内容,其他语言支持敬请期待.

聊天和操作分工如下:

- **ChatVPet** 负责说话和选表情. 平时聊天直接回答, 需要查东西或者操作桌宠时再交给 **ToolCallAI**.
- **Process** 负责找相关的知识和记忆, 把玩家说的话、桌宠的回答和可用工具一起交给 **ToolCallAI** 判断.
- 桌宠插件负责实际操作, 检查数量、预算和当前状态, 做完后把结果传回来, 再让 **ChatVPet** 告诉玩家.

** **ToolCallAI** 指的是其他高智力模型, 例如 DeepSeek 或者 OpenAI 等*

比如玩家问“够不够钱买”, 就查一下价格和余额; 让买才买, 买到了再说买好了. 重新生成回答也不能再买一遍. 后面还会加上翻旧聊天、看截图和选动画, 具体写在 [ChatVPetProcess](ChatVPetProcess.md) 里.
